# MIC-770-V3

## Ringkasan
Compact fanless system dengan socket LGA1700 untuk prosesor Intel Core generasi 12/13/14 dan Series 2 (Bartlett Lake-S) hingga 65 W, tersedia dalam varian chipset R680E (I/O lengkap, NVMe, RAID) dan H610E, serta bodi Standard dan Extreme. Ekspansi melalui i-Module MIC-75.

Catatan: datasheet hanya teks; nomor halaman tidak tersedia, sumber ditulis per bagian datasheet (DS: <bagian>).

### Suhu operasi
| Konfigurasi | Airflow 0,7 m/s | Tanpa airflow |
|---|---|---|
| CPU 65 W, Standard | -20 ~ 50 °C | tidak tercantum |
| CPU 65 W, Extreme | -20 ~ 65 °C | -20 ~ 35 °C |
| CPU 35 W, Standard | -20 ~ 60 °C | tidak tercantum |
| CPU 35 W, Extreme | -20 ~ 70 °C | -20 ~ 50 °C |
| Fan kit | tidak tercantum | -20 ~ 55 °C |

NVMe M.2 (R680E) dibatasi -20 ~ 50 °C. CPU 65 W pada beban penuh dapat mengalami thermal throttling; daya CPU dapat diatur di BIOS. (DS: Environment, Storage)
